Connecting the CDO/BM app to the Web Portal

The CDO/BM app saves its data automatically as you use it. To let AM/RM/PM/HO see that real data instead of mock data: open the CDO/BM app → menu (⋮) → Export Database (.json) → then in the Web Portal, click the 📂 icon in the top bar and select that file. It replaces the Mirpur-2 branch's mock records with the real ones — the other branches stay as mock data for comparison.
This is a UI showcase built against the Schedule Miss Register BRD. The CDO/BM app persists its data locally (auto-saved, with Export/Import and a Time Simulator for testing day/week/month jumps). The Web Portal's own dataset is in-memory mock data each load, unless you import a real export as described above. Keep all three files in the same folder for the links above to work.
